# Projection Desk

这是一个本地静态原型，用来验证“输入一句产品背景，自动拆出参考产品并做三年收入预估”的流程。

## 当前能力

- 输入产品名和一句背景描述。
- 自动识别题材、玩法、IP、商业化和目标市场。
- 自动生成：
  - 下载参考池
  - 变现参考池
  - 生命周期参数
- 输出：
  - 首年收入：保守 / 乐观
  - 前三年收入：保守 / 乐观
- 支持：
  - 手动调整下载捕获率
  - 手动调整 RPD 权重
  - 手动调整生命周期参数
  - 导出当前预估为独立 HTML 快照

## 数据口径

当前样本库不是 live API 直连，而是从已安装的 `sensor-tower-workflow` 样本报告整理出来的本地参考数据。

优点：

- 页面可直接运行，不依赖 token。
- 每条参考产品都保留了样本来源文件。
- 可以先验证产品逻辑、交互和估算模型。

限制：

- 目前覆盖偏手游。
- 观测窗口不统一，有 5 个月、6 个月、10 个月、12 个月几种。
- 页面内把它们统一成了“观测值 + 年化参考值”。

## 打开方式

直接用浏览器打开 [index.html](D:/AI/TOOLestimation/index.html)。

## 后续接 live Sensor Tower

下一步建议把这个静态页面接到一个后端服务：

1. 输入产品背景后，先做标签识别。
2. 根据标签从本地参考库挑候选产品。
3. 如果本地有 `SENSOR_TOWER_API_TOKEN`，再补拉这些候选的实时下载 / 收入。
4. 回填到前端，替换本地样本库中的旧值。

这版原型已经把“参考产品池”“变现池”“生命周期参数”“快照导出”都拆好了，后端只需要补数据接口，不需要重做页面结构。
